# 古风提示词 · 月下剑舞（高分辨率直出专用）

> 配套 `minimax_h3_studio_ui.json` 图片模块（30 步 res_multistep）。
> TE 为 Qwen3-VL-32B，原生支持中文；中文出图质量未实测，建议同 seed 跑英文版对比。
> 用法：整段复制进 studio 图片模块的 prompt 框 → Queue。

## 提示词正文（约 500 字）

```text
巨幅中国古风奇幻画卷，月下剑舞：巍峨群峰之上万顷竹海如碧涛翻涌，云雾在山腰间缓缓流淌，一轮满月悬于天穹，清辉如水银泻地。画面中心，一位绝世白衣女剑客独立于孤峰之巅的青石平台，衣袂如雪，广袖与三丈白绫在夜风中猎猎飞舞，乌黑长发间一支白玉簪微颤，发丝与月华交织成霜色流光。她侧身回眸，眉目如画，神情清冷孤傲，眸中一点星光与手中长剑遥相呼应——剑身流转青碧色灵光，光纹如活物游走，剑尖轻挑，挑落的樱花瓣与竹叶在空中盘旋成环。脚下青石镌刻古老符文，符文微亮与月色共鸣；身后一株千年垂樱自崖壁探出，花瓣纷飞如雪，掠过剑锋时被青光染成淡青色。远处飞瀑如练，自千仞绝壁倾泻而下，水雾中隐约可见一座飞檐画楼悬于云端，灯笼暖光点点，与冷月清辉形成冷暖对比。天际流云呈绸缎质感，被月光镀上银边；地平线处群山剪影层峦叠嶂，渐次隐入淡紫色夜霭。构图采用低角度仰拍，前中后三景纵深分明：前景飘落的花瓣虚化成朦胧光斑，中景人物与剑光锐利清晰，远景山楼云瀑层层递进。整体色调以月白、黛青、竹绿为主，点缀剑光青碧与灯笼暖橙；光影如工笔重彩般细腻，国风幻想美学，水墨与写实融合的数字绘画，细节纤毫毕现，超高清质感，无文字，无水印。
```

## 要素拆解（便于替换改造）

| 维度 | 内容 | 可替换项 |
|---|---|---|
| 主体 | 白衣女剑客 / 回眸 / 持剑 | 换人物身份、姿态、服饰色系 |
| 环境 | 竹海 + 孤峰 + 满月 + 飞瀑 + 云端画楼 | 换场景元素（雪原 / 江南水乡 / 大漠孤城） |
| 光影 | 月华清辉 + 剑身青光 + 灯笼暖橙（冷暖对比） | 换光源（晨曦金 / 烛火 / 极光） |
| 构图 | 低角度仰拍 + 三景纵深 + 前景虚化 | 换视角（平视全景 / 高空俯瞰 / 特写） |
| 色调 | 月白 / 黛青 / 竹绿 + 青碧 / 暖橙点缀 | 换主色调 |
| 风格 | 国风幻想美学 / 水墨×写实融合 / 工笔重彩光影 | 换画风（纯水墨 / 厚涂 / 电影 CG） |
| 质量词 | 细节纤毫毕现 / 超高清质感 / 无文字无水印 | 固定保留，防文字水印伪影 |

## 配套参数（studio 默认值）

- 分辨率默认 **2048×1152**（已验证清晰档）；高分辨率请用 **32 倍数网格**——4K 用
  **4096×2304**，⚠️ 3840×2160 的 2160 非 32 倍数，真机实测发糊（踩坑记录坑 9）
- 30 步 res_multistep / simple、`VAEDecodeTiled` tile 1024
- `noise_seed` 42（fixed）：同 seed 换提示词可对比画风；想探索新构图改 seed
- 快速预览：steps 调回 6 + 1344×768，构图满意再切高分辨率正式出片
- 视频模块联动：出图后框选视频组 Ctrl-B 解除旁路 → 同图直接动起来
